https://mavenanalytics.io/data-playground/restaurant-orders

## Project Overview
This project uses PostgreSQL to analyse restaurant order data by combining order details and menu information. The analysis explores meal prices, order values, sales performance and category-level trends.

## Tools
- PostgreSQL
- pgAdmin 4

## SQL Techniques
- Creating tables using `CREATE TABLE AS`
- Joining tables using `JOIN` and `ON`
- Aggregate functions: `SUM()`, `AVG()`, `MAX()` and `MIN()`
- Grouping data using `GROUP BY`
- Sorting results using `ORDER BY`
- Filtering results using `LIMIT`
- Rounding numerical values using `ROUND()`

## Analysis Performed
1. Combined order details and menu item records.
2. Identified the most and least expensive meals.
3. Calculated total sales.
4. Calculated the total amount spent per order.
5. Identified the highest and lowest orders.
6. Analysed the highest and lowest meal prices by category.
7. Calculated total sales by category.
8. Compared average meal prices across categories.
